About me

I'm Stenio Ignacio, a DevOps / DevSecOps Engineer focused on integrating security across the development lifecycle — from code to deploy. I work with major clouds (AWS and GCP) and I'm proficient in Infrastructure as Code with Terraform and OpenTofu.

I apply SAST, SCA and DAST practices to ensure every line of code is delivered securely. I write automations in Bash, Python and PowerShell to increase platform teams' efficiency.

I'm an enthusiast for Kubernetes and self-hosted open source tools — GitLab, SonarQube, ArgoCD and others running on your own infrastructure, with full control and data sovereignty.
